## ⚡ Step-by-Step Instructions

1. **Open AI Studio:**
   - In Incognito, navigate to `https://aistudio.google.com/` using the student credentials provided in the lab panel.
   - Accept the terms of service.

2. **Task 1: Create a System Instruction Prompt:**
   - Click **Create new prompt** > **Chat prompt**.
   - In **System Instructions**, paste:
     ```
     You are a helpful culinary expert. Suggest quick, nutritious recipes based on user ingredients.
     ```
   - In User prompt, type:
     ```
     I have eggs, tomatoes, and spinach. What can I make?
     ```
   - Click **Run** to generate the response.

3. **Task 2: Multimodal Image Understanding:**
   - Click **Create new prompt** > **Freeform prompt**.
   - Click the **+** (Insert image) icon and upload or select any sample image (or public image URL).
   - In the prompt box, type:
     ```
     Describe this image and identify the main objects present.
     ```
   - Click **Run**.

4. **Task 3: Export Prompt Code:**
   - In the top right corner of the prompt editor, click **Get code**.
   - Select **Python** and copy the code.
