# 🚀 Google Cloud Study Jams - 10/10 Skill Badges Speedrun Guide

Complete, verified, and 1-click solutions for all **10 Required Skill Badges** in the **Google Cloud Learn with Communities (Study Jam)** program.

> [!TIP]
> **⚡ The Golden Speedrun Trick (Save 20+ Hours):**
> You **do NOT need to do all 5-6 prerequisite learning labs** inside each course! 
> 1. Run the **Challenge Lab** directly using the scripts in this repository to get **100/100 score**.
> 2. Click **End Lab**.
> 3. Go to the course catalog, open the **`Course | Skill badge`** card, and simply click **`Start`**.
> 4. **BOOM!** The system detects your 100% challenge lab score and immediately awards **"COURSE COMPLETED ✓"** and unlocks your official Skill Badge in 5 seconds!

## 🛠️ General Instructions (Read Before Starting)

1. **Always use an Incognito / Private Window** when opening Google Cloud Console to prevent account collision with your personal Gmail.
2. Open **Cloud Shell** (`>_`) in Google Cloud Console.
3. Paste the corresponding badge script from this repo into Cloud Shell.
4. Wait for `=== COMPLETED ===` message, then click **Check my progress** on all tasks to get **100/100 score**.
5. Click **End Lab**.
6. Search the course name on Google Skills Boost catalog, click the **`Course | Skill badge`** card, and click **`Start`** to claim the badge.
