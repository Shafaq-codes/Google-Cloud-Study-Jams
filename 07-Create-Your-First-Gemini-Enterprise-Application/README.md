## ⚡ Assessment Answers Key

Open the Assessment inside the course and select the following answers:

### Question 1:
**Which of the following describes a key capability of Gemini Enterprise?**  
- **Correct Answer:** It provides enterprise-ready access to Google's most capable AI models with built-in data privacy and security.

### Question 2:
**How does Gemini Enterprise ensure customer data privacy?**  
- **Correct Answer:** Customer data and prompts are not used to train Google's models without permission.

### Question 3:
**What is the primary interface for developers to build prototypes quickly in Gemini Enterprise?**  
- **Correct Answer:** Google AI Studio / Vertex AI Studio.

### Question 4:
**Which capability allows Gemini to interact with external systems, APIs, or databases?**  
- **Correct Answer:** Function Calling / Tools.

### Question 5:
**Which model tier is best suited for high-volume, low-latency multimodal tasks?**  
- **Correct Answer:** Gemini Flash (e.g. Gemini 1.5 Flash / 2.0 Flash).

### Question 6:
**What parameter controls the randomness or creativity of Gemini's responses?**  
- **Correct Answer:** Temperature (lower values for deterministic, higher for creative).

### Question 7:
**What is Grounding in Gemini Enterprise?**  
- **Correct Answer:** Anchoring model responses in verifiable enterprise data sources or Google Search to prevent hallucinations.

### Question 8:
**Which SDK library is recommended for interacting with Gemini APIs in modern Python applications?**  
- **Correct Answer:** `google-genai` (Google Gen AI SDK).
